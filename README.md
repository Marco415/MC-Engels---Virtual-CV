# MC-Engels---Virtual-CV

## Hosts website for Virtual CV



The website serves as an online CV that shows my accomplishments, skills, education history, qualifications, and other details. The website is hosted on GitHub and the link can be found there as well.



This is a static website created with HTML, CSS, and JavaScript. The website is divided into four sections:
- Home page
- Resume page
- Projects page
- Certificates page



The home page contains basic information, such as my email and skills.
The resume page contains a copy of my CV.
The projects page contains a list of the projects I have worked on, including a short description and GitHub link for each.
The certificates page contains a list of all the certificates I have received.
